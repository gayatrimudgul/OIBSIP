# Car Price Prediction with Machine Learning

## Internship
Oasis Infobyte — Data Science Internship

## Task
Task 3: Car Price Prediction with Machine Learning

## Objective
Predict the selling price of used cars using machine learning techniques.

## Work Completed
- Data cleaning and preprocessing
- Car age feature engineering
- Car brand feature engineering
- Exploratory Data Analysis (EDA)
- Price distribution analysis
- Selling price vs fuel type analysis
- Selling price vs car age analysis
- Correlation heatmap
- Categorical feature encoding
- Train-test split
- Linear Regression
- Random Forest Regression
- Model evaluation using MAE, RMSE and R²
- Feature importance analysis
- Model comparison and conclusion

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Project File
`Car_Price_Prediction.ipynb`

## Result
Random Forest Regression performed better than Linear Regression on the test dataset.

## Conclusion
The project demonstrates how machine learning can be used to predict used-car selling prices based on vehicle characteristics.
