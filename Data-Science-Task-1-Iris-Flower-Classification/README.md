# Iris Flower Classification

## Internship
Oasis Infobyte — Data Science Internship

## Task
Task 1: Iris Flower Classification

## Objective
Train machine learning classification models to identify the species of an Iris flower — Setosa, Versicolor, or Virginica — using physical measurements.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

## Work Completed
- Exploratory Data Analysis (EDA)
- Dataset shape, data types, missing-value check, and descriptive statistics
- Pairplot and box plots
- Feature selection discussion
- 80/20 train-test split
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Accuracy evaluation
- Confusion matrices
- Classification reports
- Model comparison and conclusion

## Dataset
The Iris dataset was loaded directly using `sklearn.datasets.load_iris()`. No external dataset download was required.

## Project File
`Iris_Flower_Classification.ipynb`

## Result
Both Logistic Regression and KNN achieved excellent performance on the test dataset.

## Conclusion
The project successfully demonstrates Iris flower species classification using machine learning techniques.
