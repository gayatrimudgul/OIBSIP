# Unemployment Analysis with Python

## Internship
Oasis Infobyte — Data Science Internship

## Task
Task 2: Unemployment Analysis with Python

## Objective
Analyze unemployment trends in India using Python and data visualization techniques.

## Work Completed
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Monthly unemployment trend analysis
- Comparison of unemployment trends across major regions
- Top 10 regions by average unemployment rate
- Correlation analysis of unemployment, employment, and labour participation
- COVID-19 impact analysis
- Key observations and conclusion

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project File
`Unemployment_Analysis.ipynb`

## Conclusion
The analysis examined unemployment patterns across different regions and time periods in India and compared unemployment before and during the COVID-19 period.
